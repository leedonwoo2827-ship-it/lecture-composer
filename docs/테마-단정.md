# 영상 테마 「단정 스케치북」(danjeong)

이 문서는 영상 테마 「단정 스케치북」의 디자인 규칙, 어떤 코드가 바뀌었는지, 그리고 회사 PC에 적용하는 방법을 정리한 것입니다.
읽는 사람은 회사 PC에서 이 레포를 적용하는 사람과 Claude Code입니다.

`lecture-composer`의 영상 룩(look, 화면 디자인)을 갈아 끼우는 테마입니다. 테마를 켜지 않으면 기존 아이보리 룩(`ivory`)이 그대로 나옵니다.
기준 커밋은 회사 원본 `52ebd4a`이고, 이 레포는 그 위에 테마 커밋을 얹었습니다.

## 1. 무엇이 바뀌나

| 층 | 기존(ivory) | 단정(danjeong) |
|---|---|---|
| 글꼴 | Pretendard. 400·600·700만 있고 800은 합성 | **SUIT 400–900을 레포에 동봉.** 제목 900, 라벨 머리 800 |
| 바탕 | 아이보리 단색, 또는 codex가 그린 16:9 배경 | **덩이(소주제 묶음)마다 바탕이 바뀜.** 종이 → 하늘 → 세이지 → 살구 순서로 돌고, 종이 결(SVG 잡티)을 깐다 |
| 그림 | codex 16:9 배경. 오른쪽 아래 25%에 작은 플랫 그림 | **codex 투명 PNG 사물 하나**(굵은 먹선 손그림과 플랫 채색)를 오른쪽 큰 덩어리(blob) 위에 얹는다 |
| 장식 | 없음 | 반짝이·별·점·동그라미·화살표. 선은 **그어지며** 나타난다 |
| 제목 | 왼쪽 위 적갈색 한 줄 | 키커(`01 — 정규화`, 자간을 넓게) → 굵은 제목 2줄(둘째 줄은 강조색) → 물결 밑줄이 그어진다 |
| 라벨 | 남색 글자 + 빛 띠 | `01` 번호 + 굵은 머리. **말하는 순간에 타이핑**되고, 설명은 그 뒤에 떠오른다 |
| 머리말·꼬리말 | 없음 | 왼쪽 위 로고타입 `SQLD.`, 오른쪽 위 캡션 `SQLD 종합본 — L03`, 아래에 점 페이저와 `02 / 08` |
| 강 표지·맺음 | 아이보리 | 깊은 남색 바탕, 큰 제목, 토마토색 덩어리 위에 사물 |
| 도식 | 흰 카드 + 그림자. 노트 SVG를 그대로 씀 | **Claude가 테마 스타일로 다시 그림**(글자와 구조는 원본 그대로). 먹선 카드에 단색 그림자를 비껴 깔고, 손그림 흔들림 필터를 건다 |
| 표 | 남색 머리행, 줄무늬 | 먹선 괘선, 머스터드 머리행 |
| 문제 카드 | 흰 카드, 남색 | 먹선 카드, 토마토색 칩, 깊은 남색 코드 상자 |
| 썸네일 | 아이보리 + 과목색 | 깊은 남색 + 큰 강 번호(머스터드) + 덩어리 |
| 등장 시각 | 문장 시작(글자 수 어림) | **STT 단어 시각.** 라벨 글자를 실제로 말하는 순간에 맞춘다(없으면 글자 비례) |

| 토큰 | 값 | 쓰임 |

## 2. 켜는 법

`jobs/<잡>/job.json`:
```json
"backplate": { "theme": "danjeong", "image_mode": "section", "bg_per_section": 3 },
"manuscript": { "redraw_figs": true }
```
- `image_mode: section`이면 덩이마다 사물 하나를 codex가 그립니다. 한 섹션에 `bg_per_section`장입니다.
  사물은 `jobs/<잡>/objects/`에 캐시되므로, 같은 주제는 다른 강에서도 다시 그리지 않습니다.
- `image_mode: none`이면 사물 없이 바탕·덩어리·장식만 나옵니다. codex를 쓰지 않습니다.
- 예시 잡은 `jobs/sqld-danjeong-sample/job.json`입니다.

## 3. 명령

| 명령 | 하는 일 |
|---|---|
| `.venv\Scripts\python tools\theme_preview.py` | **미리보기.** 집필 없이 SQLD 샘플 8장을 굽는다 → `out/theme-preview/danjeong/contact.png` |

| `run.bat render --job J --only L01 --sections 1` | 실제 1섹션 시험 |

## 4. 말소리 동기화(`engine/backplate/render/sync.py`)

1. 대본(`data-say`)을 음절 열로 바꾼다(공백·부호 제거).
2. 장마다 TTS wav를 **faster-whisper**로 받아 적어 단어 시각을 얻는다. 결과는 `*.words.json`에 캐시한다.
3. STT 음절과 대본 음절을 맞대어(difflib) 대본 음절마다 시각을 얻는다. 발음이 다른 자리는 보간한다.
4. 라벨 머리글을 대본에서 찾는다(완전 일치, 없으면 가장 긴 공통 조각).
   → `at`은 그 자리 시각에서 0.25초를 뺀 값, `say_end`는 다 말한 시각이다. 타이핑 속도는 이 둘로 정한다.
- faster-whisper가 없거나 실패하면 **글자 비례**로 맞춥니다. 렌더는 멈추지 않습니다.
- 끄려면 환경변수 `BP_SYNC=off`, STT만 끄려면 `BP_SYNC=text`를 줍니다. 모델은 `BP_SYNC_MODEL`로 고르고 기본은 `small`입니다.
- 설치(엔진 venv): `engine\backplate\.venv-app\Scripts\pip install -r requirements-sync.txt`.
  처음 한 번 모델을 받습니다(small 약 460MB).

## 4-2. 섹션(≈10분) 이음매
섹션마다 따로 굽고 s4 가 `-c copy` 로 잇는다(원래 레포와 같음). 테마의 번호는 **강 전체 기준**으로 센다 — `s3_render.lecture_span()` 이 앞 섹션 원고에서 장·소주제·덩이 수를 누적해 장마다 `look.page/pages/chunk`·키커 번호로 싣는다.
- 쪽수 `07 / 112` 가 섹션을 넘어 이어진다. 강 전체가 24장을 넘으면 점 페이저 대신 가는 진행선.
- 키커 번호(소주제)와 바탕 순환도 이어진다 → 이음매 앞뒤가 한 강처럼 보인다.

## 6. 회사 PC 적용 절차

**A. 이 레포를 그대로 쓴다(가장 쉬움)**
```bat
git clone https://github.com/leedonwoo2827-ship-it/lecture-composer-danjeong
cd lecture-composer-danjeong
setup.bat
engine\backplate\.venv-app\Scripts\pip install -r requirements-sync.txt
```
원천(`_assets`의 요약노트·문항)을 기획 화면에서 `jobs/<잡>/input/`으로 가져온 뒤, 목표서에 `backplate.theme: "danjeong"`을 적습니다.

**B. 회사 최신 lecture-composer에 테마만 얹는다**
```bat
cd <회사 lecture-composer>
git fetch https://github.com/leedonwoo2827-ship-it/lecture-composer-danjeong main
git diff 52ebd4a FETCH_HEAD > ..\danjeong.patch
git apply --3way ..\danjeong.patch
```
충돌이 나면 VSCode의 Claude Code에 이렇게 말합니다.
"docs/테마-단정.md 의 5절 목록대로 단정 테마를 이식해 줘. theme 가 없을 때 기존 룩이 한 픽셀도 바뀌면 안 된다."

**적용 확인**
1. `tools\theme_preview.py --theme ivory`가 기존 L19 룩과 같은지 확인합니다.
2. `tools\theme_preview.py`의 `contact.png`를 확인합니다.
3. `run.bat render --job <잡> --only L01 --sections 1`로 실제 1섹션을 확인합니다.

## 7. 사물(오브젝트) 프롬프트 규칙

`longform/s3_render.py`의 `object_prompt()`에 있습니다.
- 주제를 상징하는 **구체적인 물건 하나**를 그린다(DB 원통·서랍장·열쇠·돋보기·깔때기·퍼즐·자물쇠·표 카드·톱니바퀴 등).
- 굵고 살짝 흔들리는 검은 먹선, 플랫 채색, 두 톤 음영, 짧은 흰 하이라이트, 옅은 종이 그레인, 3/4 각도로 그린다.
- **투명 배경**(`CODEX_IMAGE_BACKGROUND=transparent`). 글자·숫자·로고·얼굴은 넣지 않는다. 1:1 캔버스의 75–85%를 채운다.
- 캐시 키는 프롬프트 해시입니다. 스타일 문구를 바꾸면 다시 그립니다.
