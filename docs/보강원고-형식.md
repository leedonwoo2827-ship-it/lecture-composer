# 보강 원고 — 본편 뒤에 붙이는 「3과목 · 보강」(용어학습·개정 주제)

본편(1·2과목 강)을 **건드리지 않고** 강을 뒤에 덧붙이는 자리입니다.
출제기준에는 있는데 원천에 없는 주제나 용어학습 같은 원고를 나중에 기획해서 넣을 때 씁니다.

## 1. 어떻게 붙나
- 보강 원고는 **세 번째 과목 파일**로, **같은 파일을 두 곳에** 넣습니다: `jobs/<잡>/input/scripts/03-보강_원고.html`(내레이션)과 `jobs/<잡>/input/notes/03-보강.html`(편성 구조).
  요약노트가 있는 잡은 편성 구조를 요약노트가 정하므로, 영상 원고 칸에만 넣으면 강에 들어가지 않습니다.
- 편성(s1)은 과목마다 강 수(`curriculum.lectures_per_subject`)를 따로 나눕니다. 그래서 1·2과목 강(예: SQLD L01~L20)은 **그대로** 두고, 보강은 그 뒤 번호(L21~)로 붙습니다.
- 교재(s8)에도 「3과목 · 보강」으로 들어갑니다.

## 2. 형식 — 기존 영상 원고와 같다
| 위치 | 규칙 |
|---|---|
| h1 | `3과목 · 보강 — 용어학습·개정 주제`. **「N과목」**의 숫자가 과목 번호가 된다(「3부」는 못 읽음). `data-say`(여는 말) · `data-outro-say`(닫는 말), 발음이 다르면 `data-read` · `data-outro-read` |
| h2 | 절 = 편성 단위. `1. 정규 표현식`처럼 번호 + 제목 |
| h3 | 장 하나. `data-id`(고유 이름표, 예: `q3-01-02`) · `data-say`(자막 = 내레이션) · 필요하면 `data-read`(소리 나는 대로, 예: REGEXP_LIKE → 레젝스프 라이크) |
| h3 본문 | 화면에 나올 판서(짧은 목록), 표, SQL 코드 블록(`<pre>`), SVG 도식 |
| 문항 배지 | 근거 문항이 있으면 h2·h3 안에 `<span class="qn">모의 3회 12번</span>` — 기출 맛보기 고르기에 쓰인다(화면에는 회차를 쓰지 않는다) |

## 3. 용어학습 원고 쓰는 법
- h2 하나에 **비슷한 묶음**(예: 「2. 조인 용어」), h3마다 **용어 1개**.
- h3 `data-say`는 **정의 → 짧은 예 → 시험에서 갈리는 점** 순서로 3~5문장(약 20~40초) 씁니다.
- 판서는 용어 · 한 줄 정의 · 헷갈리는 짝(예: `UNION ↔ UNION ALL`)을 적습니다.

## 4. 넣은 뒤
```bat
run.bat propose --job sqld                     :: 3부 분량 확인
run.bat decide  --job sqld --per 5,15,2 --target 30 --note "보강 2강 추가"
run.bat make    --job sqld --only L21,L22      :: 보강 강만
```
이미 만든 강은 원고·영상이 그대로 남습니다(입력 해시가 같으면 건너뜀).
