# 원천 가져오기 — 책 폴더에서 무엇을 가져오나

문항은 별도의 **문항 앱**이 자동 생성하고, 그 결과는 과정마다 따로 있는 **책 폴더**에 쌓입니다.
이 레포는 그중 필요한 파일만 **복사**해서 `jobs/<잡>/input/`에 넣습니다. 이후 실행은 그 사본만 봅니다(다른 폴더에 의존하지 않음).

## 1. 책 폴더 구조(표준)

| 폴더/파일 | 내용 | 이 레포가 쓰나 |
|---|---|---|
| `_book.json` | `{"pd": "<품목 코드>", "label": "…"}` | ✅ 품목 코드(pd)를 목표서 `register.pd`와 설명란 링크(`register.site_url_template`)에 넣음 |
| **`_rounds/mNN.json`** | **회차별 모의고사 원본** — 문제·지문·보기·정답·해설·**explanation_speech(말 해설)**·과목 번호·태그, 그림 SVG(`assets[].svg`)까지 한 파일에 | ✅ **필수** → `input/rounds/` |
| `03/summary_*.html` | 과목별 요약노트(h2 섹션 · h3 소주제 · 「모의 N회 M번」 배지) | ✅ 요약노트 → `input/notes/` |
| `00/` · `01/` | 원본 PDF · 원본 OCR 문항(타사 원문 — 저작권상 쓰지 않음) | ❌ |
| `02/` · `04/` · `05/` | 문항 MD, 문제 영상 대본, 10문항 번들 | — (`_rounds`와 같은 내용에서 파생) |
| `06/` | 사이트 빌드 결과(`problems.json` 등) | — (`problems.json`에는 말 해설이 없음) |

**옮길 것은 `_rounds/` 폴더 하나(+ `_book.json`)면 됩니다.** 그림은 SVG 문자열로 JSON 안에 들어 있어서 따로 옮길 파일이 없습니다.

## 2. 가져오는 방법(웹앱 「기획」 화면)

- **책 폴더를 통째로 적기** — 「가져올 폴더」에 책 폴더 경로를 적으면 `_rounds/mNN.json`(문항) · `03/summary_*.html`(요약노트) · `_book.json`(품목 코드)을 알아서 가져옵니다.
- **아무 폴더나 적기** — 그 폴더 안의 파일을 내용으로 가려 넣습니다.
  h3에 `data-say`가 있는 HTML = 영상 원고 · 없는 HTML = 요약노트 · `VIDEOS_BY_TAB`이 있는 HTML = 리뷰 페이지 · `mNN.json` = 문항.
- **끌어다 놓기** — ② 원천 파일 칸의 네 자리(요약노트·영상 원고·문항·리뷰)에 파일을 직접.

상대 경로는 레포 기준입니다(예: `_context\과정이름` — `_context/`는 깃에 올라가지 않는 받아 둔 원천 자리).

### 문항이 아직 확정되지 않았을 때
기출 맛보기는 강마다 고정 예산(기본 14분)이라, 문항 없이도 편성·집필할 수 있습니다.
문항이 확정되면 넣고 `run.bat examples`(대시보드 「문항 반영」) → `compose` → `render`. 집필은 저장된 것을 재사용합니다(Claude를 다시 부르지 않음).

## 3. 영상 원고(선택, 권장)
summaryhtml2videoscripthtml 산출물(`…/10_내보내기/<과목>_원고.html`)입니다. 검수된 내레이션(`data-say`)·발음(`data-read`)·도식이 들어 있어 있으면 집필이 그것을 뼈대로 씁니다.
요약노트와 같은 순서가 되도록 파일 이름 앞에 `01-1`, `01-2` … 를 붙여 둡니다(h1의 「N과목」이 있으면 그 번호로 짝지음).
