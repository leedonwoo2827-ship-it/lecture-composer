## 반드시 지킬 것
0. {source_rule}
1. **사실은 요약노트에 있는 것만** 쓴다. 노트에 없는 정의·수치·연도·인명·사례를 지어내지 않는다.
   분량은 "왜 중요한가 → 쉬운 말로 풀기 → 노트 안의 예시 확장 → 헷갈리는 포인트 → 시험에서 묻는 방식"으로 채운다.
2. 노트의 h3 항목 하나가 group 하나다. **group 의 순서와 개수는 노트 h3 와 같다**. 각 group 의 `sub_id` 는 노트에 표시된 id 를 그대로 쓴다.
   (노트에 h3 가 없으면 섹션 전체를 group 하나로 한다. sub_id 는 섹션 id.)
3. 내레이션(`say`)은 강사가 말하는 구어체 **하십시오체**(~입니다, ~합니다, ~십시오). 한 문장은 60자 이내.
   "여러분", "자, 이제" 같은 강의 말투는 좋지만 과하지 않게. 영어 약어는 처음 나올 때 한국어로 풀어 준다.
   기호(→, ·, %, ①)와 괄호는 쓰지 말고 말로 풀어 쓴다.
   `say` 는 **자막**으로도 화면에 나간다. `say` 에 숫자·영문 약어·기호가 있으면 `read` 에 **소리 나는 대로** 적은
   발음 대본을 함께 쓴다(예: 2차원 → 이 차원, KDD → 케이디디, ARIMA → 아리마, 3V → 쓰리브이, AI → 에이아이).
   `read` 는 `say` 와 문장·순서가 같고 표기만 다르다. 바꿀 것이 없으면 `read` 는 빈 문자열.
   입력의 「기존 발음」은 이 강좌가 쓰던 읽기 방식이다 — 같은 용어는 같은 방식으로 읽는다.
4. 판서(`bullets`)는 화면에 뜨는 글자다. 한 장에 2~4줄, 한 줄 40자 이내, 명사형으로 짧게. 내레이션을 그대로 옮기지 않는다.
5. 노트에 도식(FIG)이 있으면 그 도식을 설명하는 슬라이드를 만들고 `fig` 에 FIG 번호를 넣는다. 그 슬라이드의 bullets 는 최대 2줄.
   한 FIG 는 한 번만 쓴다. 도식이 없는 슬라이드는 `fig` 를 null 로.
