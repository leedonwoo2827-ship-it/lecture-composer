새 창의 claude 에서 /login 으로 계정을 바꾸고, /usage 로 남은 사용량을 봅니다. API 키는 쓰지 않습니다(구독 로그인).

YouTube — 게시(publish)

열린 Chrome 에서 채널 관리 권한이 있는 구글 계정으로 로그인하고 Studio 가 보이면 창을 닫으십시오. 15분 넘는 영상·맞춤 썸네일은 채널 전화 인증이 필요합니다. 팀원은 각자 자기 구글 계정(채널 관리자 권한)으로 로그인합니다.

codex 계정 칸 — 배경 그림(s3c). 칸마다 따로 로그인해 두고 골라 씁니다. 한도에 걸리면 다음 칸으로 자동 전환해 남은 그림을 굽습니다.

쓰는 중칸계정마지막 갱신오늘 구움누적실패한도

로그인은 새 창에서 codex login 이 열립니다(브라우저에서 ChatGPT 로그인 → 끝나면 「새로고침」). 「로그인됨」이어도 세션이 죽어 있을 수 있습니다 — 그때 그림이 token_revoked 로 한꺼번에 실패하면 그 칸을 다시 로그인하십시오. 사용량은 이 PC 에서 구운 장수를 칸별로 센 것입니다(logs/usage.jsonl).
